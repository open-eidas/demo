Commandes en ligne de commande (CLI)

Snippets prêts à l'emploi pour horodater et vérifier vos documents depuis votre terminal.

terminal 
curl -X POST https://api.staging.open-eidas.eu/api/v1/timestamp \
  -H "Content-Type: application/json" \
  -d '{"hash": "VOTRE_HASH_SHA256", "algorithm": "sha256"}'
# 1. Générer la requête d'horodatage TSQ
openssl ts -query -data document.pdf -sha256 -cert -out request.tsq

# 2. Envoyer la requête binaire à la TSA
curl -H "Content-Type: application/timestamp-query" \
  --data-binary @request.tsq \
  https://api.staging.open-eidas.eu/tsa -o response.tsr

# 3. Vérifier le jeton avec la chaîne
openssl ts -verify -in response.tsr -data document.pdf -CAfile chain.pem
# Vérifier toutes les signatures et horodatages PAdES d'un PDF
pyhanko check-sig document-horodate.pdf
# Examiner les champs de signature et d'horodatage (Poppler)
pdfsig -nocert document-horodate.pdf
